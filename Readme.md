>> Resume Analyzer

An AI-based Resume Analyzer that analyzes a resume and provides feedback based on the selected job role.

>> Features

- Upload a resume
- Extract information from the resume
- Analyze resume content
- Provide feedback
- Job-role based analysis

>> Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript

>>Project Structure
